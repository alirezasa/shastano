# سکوی نوآوری و فناوری شستان

پورتال تبادل فناوری هلدینگ شستان روی **SharePoint Server 2019 (On-Premises)** با سه نوع کاربر:

1. **کاربر عمومی** — بدون ورود، محتوای منتشرشده را می‌بیند و برای مسائل فناورانه پیشنهاد می‌فرستد.
2. **کاربر شرکت تابعه** — اطلاعات شرکت را ثبت می‌کند؛ پس از تأیید هلدینگ منتشر می‌شود.
3. **کاربر هلدینگ** — کارتابل بررسی، تأیید/برگشت/رد و مدیریت همه‌ی اطلاعات.

## اجرای سریع

```bash
npm install
npm run build
npm run serve   # http://localhost:8080
```

خروجی `npm run build` در پوشه‌ی `dist/` ساخته می‌شود. این پوشه **در Git نیست** (فایل‌های تولیدی باعث کانفلیکت می‌شوند)؛
بعد از هر `git pull` دوباره `npm run build` بگیرید و خروجی را commit نکنید.

- `dist/` — نسخه‌ی پیش‌نمایش محلی (با داده‌ی نمایشی؛ فقط برای توسعه)
- `dist/sharepoint/` — **بسته‌ی استقرار شیرپوینت** (مستر پیج، صفحات، فایل‌های قالب، هندلرها و اسکریپت‌های PowerShell؛ بدون داده‌ی نمایشی)

قالب اولیه برای مقایسه در `_original/` نگهداری شده است.
