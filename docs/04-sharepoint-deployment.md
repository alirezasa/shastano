# راهنمای گام‌به‌گام استقرار روی SharePoint Server 2019

> آدرس فعلی: `http://srv-shp-web:8080` — در آینده دامنه (بخش ۹).
> همه‌ی لیست‌ها، کتابخانه‌ها، ستون‌ها، گروه‌ها و مجوزها **با اسکریپت** ساخته می‌شوند؛ ساخت دستی لازم نیست
> و اجرای مجدد اسکریپت‌ها بی‌خطر است (موارد موجود حذف یا بازنویسی نمی‌شوند).
> نسخه‌ی شیرپوینت **هیچ داده‌ی نمایشی ندارد**؛ فقط ۷ حوزه‌ی فناورانه، دسته‌بندی‌ها و شرکت‌هایی که خودتان وارد می‌کنید.

## ۲. گروه‌های Active Directory

| گروه AD (پیشنهادی) | اعضا | نقش در سکو |
|--------------------|------|-----------|
| `SHN-Holding-Admins` | مدیران سامانه در هلدینگ | کارتابل + مدیریت لیست‌ها |
| `SHN-Holding-Reviewers` | کارشناسان بررسی هلدینگ | کارتابل: تأیید / برگشت / رد |
| `SHN-Company-001` ، `SHN-Company-002` ، … | کارشناسان هر شرکت | پنل همان شرکت |

> یک کاربر فقط باید عضو **یکی** از گروه‌های شرکت باشد. کاربران هلدینگ عضو گروه شرکت‌ها نشوند.
> افزودن/حذف کاربر بعدها فقط در AD انجام می‌شود (بدون تغییر در شیرپوینت).

## ۳. ساخت بسته (روی سیستم توسعه)

```bash
git pull
npm install
npm run build
# اگر سکو در ریشه‌ی http://srv-shp-web:8080 نیست:
#   Windows (PowerShell):  $env:SHN_SP_SITE="/sites/innovation"; npm run build
```

خروجی: `dist/sharepoint/` — کل این پوشه را روی سرور شیرپوینت کپی کنید (مثلاً `C:\Deploy\shastan`):

```
dist/sharepoint/
  provisioning/   اسکریپت‌ها + shastan.config.json + companies.sample.csv + lists.json
  masterpage/     shastan.master
  SitePages/      صفحات عمومی (index, challenges, challenge, companies, company, catalog, contact)
  PanelPages/     پنل شرکت و کارتابل هلدینگ
  SiteAssets/     CSS، JS، فونت، آیکن
  layouts/        فایل‌های سمت سرور (LAYOUTS\Shastan)
```

## ۴. تکمیل تنظیمات (روی سرور)

**`provisioning\shastan.config.json`**
```json
{
  "SiteUrl": "http://srv-shp-web:8080",
  "Zone": "Default",
  "EnableAnonymousOnWebApplication": true,
  "CompaniesCsv": "companies.csv",
  "Categories": ["پتروشیمی", "نفت و گاز", "پالایش و روانکار", "خدمات مهندسی", "سرمایه‌گذاری"],
  "HoldingAdminsMembers": ["AD.SHASTANGROUP.IR\\SHN-Holding-Admins"],
  "HoldingReviewersMembers": ["AD.SHASTANGROUP.IR\\SHN-Holding-Reviewers"],
  "VisitorsMembers": ["c:0(.s|true"],
  "HoldingNotifyEmails": "innovation@shastan.ir"
}
```
- `EnableAnonymousOnWebApplication`: دسترسی ناشناس را روی Zone Web Application روشن می‌کند (برای کاربران عمومی بدون ورود لازم است).
- `c:0(.s|true` یعنی «همه‌ی کاربران واردشده‌ی Windows»؛ فقط حق خواندن صفحات و محتوای عمومی را می‌گیرند.

**`provisioning\companies.csv`** — فهرست فعلی در مخزن آمده است؛ شرکت‌های دیگر را اضافه کنید. جداکننده می‌تواند
**Tab** (کپی مستقیم از Excel)، کاما یا `;` باشد؛ فایل با کدگذاری **UTF-8** ذخیره شود:
```
CompanyCode	Title	Category	Icon	ADGroup
001	شرکت پتروشیمی بوشهر	پتروشیمی	fa-flask	AD.SHASTANGROUP.IR\SHN-BUPC
002	شرکت پتروشیمی مرجان	پتروشیمی	fa-flask	AD.SHASTANGROUP.IR\SHN-MARJ
```
اسکریپت قبل از هر تغییری فایل را بررسی می‌کند (کد تکراری، نام خالی، گروه AD بدون `\`) و در صورت اشکال متوقف می‌شود.
- `CompanyCode`: فقط حروف لاتین/عدد؛ نام پوشه‌ی شرکت در لیست‌ها می‌شود و **بعداً تغییر ندهید**.
- `Category`: باید یکی از `Categories` بالا باشد.
- `Icon`: نام آیکن [FontAwesome 6](https://fontawesome.com/search?o=r&m=free&s=solid) (تا زمانی که لوگو بارگذاری شود).
- `ADGroup`: گروه AD کاربران آن شرکت به شکل `DOMAIN\Group` (چند گروه با `|`). نام گروه آزاد است؛ گروه شیرپوینت متناظر همیشه `SHN-Company-<کد>` نام می‌گیرد.

**کتابخانه‌های اسناد**

| کتابخانه | محتوا | دسترسی ناشناس |
|----------|-------|:-------------:|
| `Publications` | انتشارات و گزارش‌ها (هر فایل = یک سند با عنوان، نوع، تاریخ، خلاصه) | خواندن تأییدشده |
| `CompanyLogos` | لوگوی شرکت‌ها؛ نشانی فایل در پروفایل شرکت (ستون «نشانی تصویر لوگو») درج می‌شود | خواندن |
| `SitePages` | صفحات عمومی سکو | خواندن |
| `PanelPages` | صفحات پنل‌ها (باز کردن آن = درخواست ورود) | ✖ |
| `SiteAssets` | CSS، JS، فونت | خواندن |

> **چرا اسناد مسائل و پیشنهادها «پیوست» هستند نه کتابخانه‌ی جدا؟** پیوست دقیقاً همان مجوز آیتم را دارد: پیوست پیش‌نویس
> یک مسئله برای عموم و شرکت‌های دیگر دیده نمی‌شود و پس از تأیید همراه با مسئله منتشر می‌شود. کتابخانه‌ی جدا یعنی
> مدیریت موازی مجوزها و خطر انتشار زودهنگام فایل.

**تنظیمات هر لیست داده**: Versioning (۵۰ نسخه)، Content Approval، Draft Item Security = «فقط کاربرانی که حق ویرایش دارند»،
ستون‌ها با نام فنی انگلیسی و عنوان فارسی، ایندکس روی شرکت/حوزه/وضعیت.

**گروه‌ها و سطوح دسترسی**: `SHN-Holding-Admins` (Shastan Admin)، `SHN-Holding-Reviewers` (Shastan Reviewer)،
`SHN-Visitors`، `SHN-Company-<کد>` (Shastan Contributor = ثبت و ویرایش بدون حذف).

**سایر**: خاموش شدن MDS، فعال شدن Lockdown Mode، صفحه‌ی خانه = `SitePages/index.aspx`.

## ۸. تست

**الف) کاربر عمومی** — پنجره‌ی Private/InPrivate مرورگر، آدرس `http://srv-shp-web:8080`
- [ ] صفحه‌ی اصلی بدون درخواست نام کاربری باز می‌شود و ۷ حوزه و شرکت‌ها دیده می‌شوند.
- [ ] `http://srv-shp-web:8080/Lists/TechChallenges` و `/_layouts/15/viewlsts.aspx` برای ناشناس **باز نمی‌شود**.
- [ ] `…/PanelPages/admin.aspx` درخواست ورود می‌دهد.

**ب) کاربر هلدینگ** — ورود → «کارتابل»
- [ ] ثبت یک رویداد در «مدیریت محتوا → رویدادها» و دیدن آن در صفحه‌ی عمومی.
- [ ] بارگذاری یک گزارش در «انتشارات» و دانلود آن از صفحه‌ی عمومی.

**ج) کاربر شرکت** — ورود → «پنل شرکت» (نام شرکت در هدر نمایش داده شود)
- [ ] تکمیل پروفایل شرکت و نماینده → ارسال → در کارتابل هلدینگ دیده شود.
- [ ] ثبت یک مسئله با پیوست → ارسال → هلدینگ «برگشت جهت اصلاح» با دلیل → شرکت نظر را ببیند → اصلاح → هلدینگ تأیید.
- [ ] **کلیدی:** مسئله‌ی تأییدشده در پنجره‌ی Private (ناشناس) دیده شود. آیتم داخل پوشه‌ی شرکت است و پوشه مجوز اختصاصی دارد؛ اگر برای ناشناس دیده نشد، اسکریپت نصب را یک‌بار دیگر اجرا و موضوع را گزارش کنید.
- [ ] کاربر شرکت دیگر، پیش‌نویس شرکت اول را نمی‌بیند.

**د) فرم‌های عمومی** (ناشناس)
- [ ] ارسال پیشنهاد برای مسئله‌ی باز با فایل PDF → کد رهگیری → در «پیشنهادهای دریافتی» هلدینگ و شرکت صاحب مسئله.
- [ ] فرم تماس → کد پیگیری → «پیام‌های تماس» هلدینگ؛ ایمیل به `HoldingNotifyEmails`.
- [ ] کد امنیتی اشتباه → پیام خطا.

## ۹. انتقال به دامنه (آینده)

1. رکورد DNS و گواهی SSL برای دامنه (مثلاً `innovation.shastan.ir`).
2. Central Admin → **Alternate Access Mappings** و گسترش Web Application به Zone **Internet** با HTTPS، دسترسی ناشناس و **FBA (LDAP)** + صفحه‌ی ورود `/_layouts/15/Shastan/login.aspx` — جزئیات کامل در [`02-authentication-fba-ldap.md`](02-authentication-fba-ldap.md).
3. به گروه‌های شیرپوینت، معادل FBA گروه‌های AD را اضافه کنید (Role Claim)، و به `SHN-Visitors` مقدار `c:0(.s|forms:shastanldapmember`.
4. در `shastan.config.json` مقدار `Zone` را `Internet` کنید و `Install-ShastanPortal.ps1` را دوباره اجرا کنید.
5. **نیازی به build یا استقرار مجدد صفحات نیست**؛ همه‌ی لینک‌ها نسبی (`/SitePages/...`) هستند.

## ۱۰. رفع اشکال

| نشانه | علت محتمل |
|-------|-----------|
| کاربر عمومی پنجره‌ی نام کاربری می‌بیند | دسترسی ناشناس روی Zone یا روی کتابخانه‌های `SitePages` / `SiteAssets` خاموش است؛ `Install-ShastanPortal.ps1` را دوباره اجرا کنید |
| صفحه بدون ظاهر (بدون CSS) | `SiteAssets/shastan` بارگذاری نشده یا برای ناشناس قابل خواندن نیست |
| «sp.js در صفحه بارگذاری نشده است» هنگام ذخیره | مستر پیج قدیمی در Cache مرورگر؛ Ctrl+F5 |
| نام شرکت در پنل نمایش داده نمی‌شود / «دسترسی ندارید» | کاربر عضو گروه AD شرکت نیست، یا گروه AD در `SHN-Company-<کد>` نیست؛ Session مرورگر را ببندید (نقش ۱۰ دقیقه Cache می‌شود) |
| خطای ۵۰۰ در ارسال پیشنهاد | لاگ ULS با دسته‌ی `Shastan` را ببینید؛ معمولاً نام لیست/ستون یا Outgoing e-mail |
| ایمیل ارسال نمی‌شود | Outgoing E-mail تنظیم نیست، یا گیرنده کاربر سایت نیست (برای `SendEmail` سمت کاربر) |

## ۱۱. تنظیمات پیشنهادی سایت

- Site Settings → Regional settings: Time zone = `(UTC+03:30) Tehran`، Locale = فارسی.
- صفحات سکو تاریخ را خودشان شمسی نمایش می‌دهند؛ این تنظیم برای نمای لیست‌ها در محیط شیرپوینت است.
- اگر Language Pack فارسی نصب است، منوهای خود شیرپوینت (تنظیمات، لیست‌ها) هم فارسی خواهند بود.
